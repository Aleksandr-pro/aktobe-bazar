# BazarFX — два трека развития

Технология живёт в двух формах. Они не заменяют друг друга: у каждой свой
потолок возможностей.

## 1. Android-оверлей (APK, текущая версия 1.6)

Что делает: снимает экран через MediaProjection и показывает улучшенную копию
поверх игры. Работает с **любой** игрой без root и без доступа к исходникам.

Плюсы:
- ставится на телефон и работает сразу, ничего не надо пересобирать;
- нейросеть обучена и крутится на GPU телефона (`AI · нейро`).

Ограничения (принципиальные, не баги):
- кадр уже отрендерен — FPS самой игры не растёт;
- задержка в 1–2 кадра и блокировка системных скриншотов (FLAG_SECURE);
- нет доступа к буферам движка (глубина, векторы движения, G-буфер).

Развитие: качество сети (больше каналов при той же скорости), пресеты под
конкретные игры, запись/сравнение, экономия батареи.

## 2. Интеграция в движок (Unity-пакет 1.6)

Что делает: сцена рендерится в низком разрешении, сеть восстанавливает кадр
внутри рендер-пайплайна. Это то, как устроены DLSS/XeSS/FSR.

Плюсы:
- **реальная экономия**: меньше пикселей геометрии и шейдинга → растёт FPS;
- нет задержки захвата, работают скриншоты и запись;
- можно дойти до G-буферов и motion vectors → качество уровня DLSS.

Ограничения:
- нужна своя игра или исходники;
- настраивается в проекте (Built-in RP или URP).

План развития (по возрастанию сложности):
1. **Сейчас:** SR по цвету + TAA по motion vectors (готово).
2. Motion-векторная репроекция истории через сеть (вместо variance clipping).
3. Подача глубины как 4-го канала: сеть учится не «размыливать» края объектов.
4. Дообучение на арт-стиле конкретной игры (`scripts/train_sr.py` + свои кадры).
5. Генерация кадров (frame generation) на уровне презентации.

## Общее ядро

Обе версии используют **одни и те же веса** (`SRWeights.java` для Android,
`BazarFXNeuralWeights.hlsl` для Unity, генерируются из одного источника).
Любое улучшение сети автоматически попадает в обе версии.

Проверки, которые ловят ошибки до устройства:
```bash
python3 scripts/check_sr_weights.py    # упаковка весов для GLES
python3 scripts/check_unity_shaders.py # HLSL-симуляция против модели
npm run check:shaders:android          # синтаксис GLES-шейдеров
```
