# Horizon Aktobe — мобильная гонка по степи в браузере

Играбельный прототип «Forza Horizon для телефона»: открывается по ссылке,
без установки и без магазина приложений. Степь Актюбинской области, трасса на
1.6 км, трамплины, солончак, заносы, пыль из-под колёс и рекорд трассы.

Страница: **`/horizon`** (на телефоне — горизонтально, лучше всего в Chrome/Safari).

## Честно о названии

Forza Horizon — торговая марка Microsoft / Playground Games. Мы не портируем
их игру, не используем их ассеты, машины, музыку и название. «Horizon Aktobe» —
самостоятельный проект в жанре open-world racer: своя степь, своя трасса, свои
низкополигональные машины. Жанр и ощущение — да, знакомые; контент — наш.

## Что уже работает

| Что | Как сделано |
| --- | --- |
| Мир 1400 × 1400 м | процедурная генерация из seed: fbm-рельеф, горное кольцо, солончак, меловые обрывы |
| Трасса 1.6 км | Catmull-Rom по контрольным точкам, сглаженный профиль высот, кюветы, разметка |
| Декор | ~2000 объектов инстансингом: саксаул, кусты, камни, вышки связи, склады-ангары, юрты у старта |
| Машины | 2 класса с разными массами/сцеплением, низкополигональные модели из кода (никаких .glb) |
| Физика | снос осей, сцепление по покрытию, ручник, нитро, уклон, прыжки с трамплинов, вязкий солончак |
| Эффекты | пыль (шейдерные точки), следы шин (инстансинг), тряска камеры, контактная тень |
| Звук | синтез через WebAudio: мотор по RPM, ветер по скорости, удары и приземления |
| Интерфейс | спидометр, передачи, нитро, мини-карта с прогрессом, отсчёт старта, финиш и рекорд |
| Управление | клавиатура, тач-кнопки, геймпад (Gamepad API) |

Рекорд трассы хранится в `localStorage` браузера — без сервера и аккаунта.

| Действие | Клавиатура | Телефон |
| --- | --- | --- |
| Газ | `W` / `↑` | кнопка «Газ» |
| Тормоз / задний ход | `S` / `↓` | «Тормоз» |
| Руль | `A` `D` / `←` `→` | ◀ ▶ |
| Ручник | `Space` | «Руч.» |
| Нитро | `Shift` | «N» |
| Вернуть на трассу | `R` | — |
| Сменить камеру | `C` | 📷 |
| Пауза | `Esc` / `P` | ⏸ |

На телефоне управление появляется само (по `pointer: coarse` или наличию
тач-событий). Портретная ориентация работает, но играть удобнее в горизонтальной.

## Как это устроено

```
lib/horizon/math.ts      шум, сглаживание, детерминированный рандом, формат времени
lib/horizon/world.ts     рельеф, трасса, декор, трамплины, высоты, коллизии
lib/horizon/physics.ts   машина, сцепление, прыжки, камера, пыль и следы
lib/horizon/input.ts     клавиатура + тач + геймпад → один Input
lib/horizon/audio.ts     WebAudio-синтез мотора, ветра и ударов
components/horizon/renderer.ts   Three.js: небо, степь, трасса, машина, частицы
components/horizon/parts.tsx     HUD: мини-карта, спидометр, тач-кнопки
components/horizon/HorizonGame.tsx  состояние игры, цикл, меню, финиш
scripts/check-horizon.mjs        смоук-тест мира и физики в Node
```

Ключевые решения:

- **Мир считается, а не рисуется.** Геометрия строится из `Float32Array` высот
  сетки 257×257; `world.ts` не импортирует Three.js, поэтому его можно гонять в
  Node и проверять без браузера.
- **Одна функция высоты.** `heightAt(terrain, road, x, z)` используют физика,
  камера, декор и рендер — машина не «плавает» над землёй и не проваливается.
- **Физика с фиксированным шагом.** 120 Гц внутри кадра, с ограничением числа
  подшагов, чтобы после сворачивания вкладки не было «телепортации».
- **Ноль внешних ассетов.** Модели машин, деревья, знамёна и текстура пыли —
  код и canvas. Страница не тянет ни одного файла картинок и звуков.

## Как проверить, не открывая браузер

```bash
npm run check:horizon
```

Скрипт компилирует `lib/horizon/*` во временную папку и проверяет:

- мир генерируется быстро, детерминированно, без `NaN` в высотах и цветах;
- трасса не проходит под деревьями и домами, старт и финиш стоят на полотне;
- машина разгоняется, тормозит, поворачивает, буксует, вязнет в солончаке;
- трамплин подбрасывает (полёт ≈ 1 с), хаотичный заезд не разваливает состояние;
- коллизии не пропускают сквозь дерево, респавн ставит машину на трассу.

Плюс общие проверки репозитория: `npm run check:types`, `npm run build`.

## Связь с BazarFX

Игра и апскейлер живут в одном репозитории не случайно. В паузе есть
**пиксельный режим**: сцена рендерится в 1/3 разрешения и растягивается
nearest-фильтром — видно ровно то, что BazarFX восстанавливает в резкую
картинку. Дальше это стыкуется напрямую:

1. игра рисует кадр в половинном разрешении;
2. `lib/fx/engine.ts` (тот же, что в `/fx`) апскейлит его до экрана;
3. FPS растёт, а картинка остаётся близкой к нативной.

Пока это два независимых прохода (демо в `/fx` и игра в `/horizon`); общий
пайплайн — следующий шаг в [`BAZARFX_ROADMAP.md`](BAZARFX_ROADMAP.md).

## Ограничения, о которых стоит знать

- Это **прототип**, а не AAA-гонка: один город-посёлок, одна трасса, две машины.
- Тени включаются на «высоком» качестве; на слабых телефонах ставь «быстрое».
- Нет столкновений машины с рельефом «в лоб» — только с декором; горы работают
  как стены по краям карты.
- Нет соперников и сетевой игры. Лучшее время — только твоё, локально.
- Интерфейс и тексты — на русском.

## Куда развивать

1. **Соперники**: призрак собственного лучшего заезда (запись состояний),
   затем боты по сплайну трассы.
2. **Трассы**: 2–3 маршрута из того же генератора (разные seed) + выбор в меню.
3. **Машины**: ещё 2–3 класса, настройка передач и сцепления.
4. **Сочность**: пыль от ветра, следы на асфальте, музыка и радио-станция,
   кат-сцены старта и финиша.
5. **BazarFX внутри игры**: рендер в 0.5× + нейро-апскейл тем же пайплайном.
6. **PWA-оффлайн**: кэш страницы через `public/sw.js`, запуск с домашнего экрана.
7. **Мультиплеер**: WebRTC-комнаты на двоих-четверых, гонка до финиша.
