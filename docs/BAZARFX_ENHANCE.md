# BazarFX 1.8 — дорисовка деталей (вторая сеть)

Пользователь: «мне нужно, чтобы ИИ дорисовывал графику, делал её лучше и
реалистичнее, пока я играю».

## Что сделано

К апскейлеру (1.6) добавлена **вторая сеть**, которая работает поверх его
результата и доделывает то, что апскейлер потерял:

```
кадр игры 1080p ──► сцена 50% ──► апскейлер ×2 ──► дорисовка ──► экран
                                    (3→8→12)        (3→8→3)
```

Это остаточная (residual) сеть: она не перерисовывает кадр, а прибавляет к нему
поправку —

```
out = sr(x) + E(sr(x))
```

## Архитектура

| Слой | Что делает |
| --- | --- |
| conv1 | 3 → 8 каналов, 3×3, ReLU, запись в две RGBA-текстуры (MRT) |
| conv2 | 8 → 3 канала, 3×3 |
| выход | `src + residual × сила` |

- 443 веса, упакованы в одну RGBA32F-текстуру (111 текселей).
- Обучение: `scripts/train_enhance.py` (numpy, без torch).
- Вход при обучении специально **деградируется** (мягкое размытие, шум, потеря
  контраста) — иначе сеть учится восстанавливать уже идеальный кадр и на
  телефоне не даёт ничего.

## Проверено симуляцией шейдеров

```
python3 scripts/check_enhance.py
  весов дорисовки прочитано: 443
  упаковка → распаковка: max|Δ| = 0.000000 — раскладка корректна
  шейдер (симуляция) vs модель: средн|Δ| = 0.000000 — совпадает
```

Симуляция повторяет шейдеры буквально: clamp по краям, texelFetch по центрам
текселей, та же упаковка весов в текстуру. Именно этот тест нашёл две ошибки до
сборки APK:

1. `conv_edge_fwd` собирала столбцы в порядке `tap × канал`, а веса — в
   порядке `канал × tap` (дало бы «мусор» на телефоне).
2. Раскладка второго слоя шла `группа × выход`, а шейдер читает `выход × группа`.

После фиксов дельта стала ровно нулевой.

## Честные цифры

| | PSNR |
| --- | --- |
| билинейный апскейл | 28.04 дБ |
| апскейлер (1.6) | 30.02 дБ |
| апскейлер + дорисовка (1.8) | **30.25 дБ** |

Прирост +0.23 дБ — небольшой. Это честно: вторая сеть не «рисует новую игру», она
убирает мягкость и возвращает часть микродеталей, которые теряет апскейлер.
Основной скачок качества даёт именно апскейлер (+1.98 дБ к билинейному).

На кропе 72×72 из середины кадра: билинейно 29.22 · апскейлер 29.83 ·
с дорисовкой **30.03** дБ.

Наглядное сравнение: `public/enhance-sample.png` — четыре плитки
(билинейно | апскейлер | +дорисовка | эталон).

## Обучение 1.9: на кадрах из игры, с целью «резче оригинала»

Первый прогон учился только на фотографиях и на реальном кадре игры давал
**отрицательный** эффект: детализация 0.0153 → 0.0143 (сеть слегка сглаживала).
Поэтому:

- в датасет добавлены кадры из игры (`scripts/data/game/*.jpg`, домен важнее
  количества фотографий — они повторяются в выборке ×4);
- цель обучения — не «оригинал», а `sharpen_target()`: тот же кадр, но с
  поднятой высокочастотной частью и подавлением ореолов. То есть сеть учится
  делать ровно то, что просил пользователь — «резче и детальнее, чем было».

Результат на кадре из CounterFlame (960×540, без масштабирования):

| | детализация (средн. градиент) |
| --- | --- |
| исходник | 0.0153 |
| + дорисовка ×1 | 0.0161 |
| + дорисовка ×2 | 0.0171 |
| + тон (пресет «Кинематограф») | **0.0189** |

## Как включить

1. Пресет **«AI · Кинематограф»** (новый в 1.8) — включает обе сети сразу.
2. Или вручную: галочка «Дорисовка деталей (вторая сеть)» + ползунок
   «Сила дорисовки деталей» (0–100%).
3. Дорисовка работает только вместе с апскейлером: без него ей нечего исправлять.

## Чиним главное: падение захвата

На реальном использовании приложение падало на старте:
`Не удалось начать захват: UnsupportedOperationException`. Пайплайн не
запускался вообще — поэтому «эффекта нет» было буквально верно.

Что сделано в 1.9:

- каждый шаг старта помечен (`получение проекции` → `показ оверлея` →
  `ожидание GL` → `создание VirtualDisplay`), и текст ошибки теперь содержит шаг,
  класс исключения, сообщение и первую строку стека;
- `createVirtualDisplay` пробует три набора флагов (AUTO_MIRROR → +PUBLIC → 0):
  на части прошивок `PUBLIC` не поддержан и бросает исключение;
- `registerCallback` больше не фатален: если прошивка не даёт зарегистрировать
  колбэк, захват продолжается;
- последняя ошибка показывается прямо на главном экране в блоке статуса.

## Цена

Вторая сеть — два дополнительных прохода по кадру в разрешении выхода апскейлера
(2× от входа). На среднем телефоне это заметно. Если FPS просел:
- включи «Авто-качество»;
- уменьши «Силу дорисовки» (0% = выключено);
- или вернись на пресет «AI · нейро» (только апскейлер).
