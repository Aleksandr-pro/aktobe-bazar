# BazarFX + CounterFlame

CounterFlame (`com.ScarletWork.CounterFlame`) — сторонняя мобильная игра под Android/iOS.
Её исходников у нас нет, поэтому важно сразу разделить два разных ответа.

## Коротко

| Что вы хотите | Что подойдёт | Можно ли применить прямо сейчас |
| --- | --- | --- |
| Резче картинка в CounterFlame, без root | **APK 1.7, пресет «Киберспорт»** | ✅ да, ставится за минуту |
| Рост FPS самой игры | нужен доступ к рендеру игры | ❌ только если у вас есть проект игры |
| Нейросеть внутри рендера (как DLSS) | Unity-пакет `BazarFX-Neural` | ⚠️ только для **своего** Unity-проекта |

Unity-пакет нельзя «наложить» на чужой APK: он подключается к рендер-пайплайну
проекта на этапе сборки (Renderer Feature / камера). Готовый APK уже собран и
подписан — вставить туда свой проход рендера без исходников невозможно.

## Сценарий A: вы играете в CounterFlame (исходников нет)

Работает только оверлей — но именно для этого он и сделан.

### Установка

1. Скачать APK 1.7:
   **https://github.com/Aleksandr-pro/aktobe-bazar/raw/apk-1.7/integrations/android/BazarFX.apk**
   Резерв: `https://cdn.jsdelivr.net/gh/Aleksandr-pro/aktobe-bazar@apk-1.7/integrations/android/BazarFX.apk`
2. Открыть файл → «Установить» (разрешить установку из неизвестных источников для браузера).
3. Запустить BazarFX → выдать **«Показ поверх других приложений»** и подтвердить
   запрос **захвата экрана**.

### Порядок запуска (важно)

```
BazarFX запущен → нажать «Старт» → свернуть → запустить CounterFlame
```

Если запустить игру раньше, оверлей просто ляжет поверх неё после старта — тоже
работает, но лучше стартовать BazarFX первым, чтобы не терять кадры при переключении.

### Настройки для шутера

В приложении выбрать пресет **«Киберспорт»** (новый в 1.7):

| Параметр | Значение | Почему |
| --- | --- | --- |
| Масштаб сцены | 1.0× | в оверлее понижение масштаба не ускоряет игру, только мылит |
| Шарп | 0.6 | силуэты врагов на дистанции читаются лучше |
| Локальный контраст | 0.5 | видно в тёмных углах Mirage/Inferno |
| Тон | 0 | не менять цвета в игре, где важна различимость скинов и моделей |
| TAA | **выкл** | иначе за бегущими остаётся шлейф |
| Генерация кадров | **выкл** | добавляет кадр задержки — в 5v5 это проигранный дуэль |

Дополнительно:
- **Пузырёк** можно перетащить в угол и уменьшить — он не мешает прицелу.
- **Разделительный экран** (слева оригинал / справа обработка) — включите один раз,
  чтобы честно увидеть, что меняется, потом выключите: он ест производительность.
- Кнопка **«Стоп»** в пузырьке снимает оверлей в любой момент — доступ к экрану
  для закрытия не нужен.

### Чего ждать честно

- **Картинка**: резче, чище края, лучше видно дальние силуэты. Это и есть выигрыш.
- **FPS игры**: не вырастет. Оверлей получает уже готовый кадр.
  Хотите больше кадров — снижайте качество графики **в настройках самой игры**
  (частота кадров, качество текстур, тени), BazarFX вернёт часть потерянной резкости.
- **Задержка**: оверлей добавляет 1–2 кадра. В тренировке и обычных катках это
  незаметно, в рейтинге на высоких рангах — ощутимо. Если задержка мешает, честный
  совет: играйте без оверлея, а BazarFX включайте для скриншотов/записи.
- **Античит**: BazarFX ничего не читает из памяти игры и не меняет её файлы — он
  снимает экран так же, как это делает запись экрана. Но правило «стороннее ПО на
  свой риск» никто не отменял: если банят за запись экрана, забанят и за оверлей.
  Не используйте в рейтинговых матчах, если дорожите аккаунтом.
- **Чёрный экран вместо картинки**: игра может выставлять `FLAG_SECURE`. Тогда
  система не отдаёт кадр ни скриншотам, ни BazarFX — это не баг, обойти нельзя.

## Сценарий B: CounterFlame — ваш проект (или есть исходники в Unity)

Тогда работает полноценный нейро-апскейл внутри рендера, с реальной экономией
пикселей и ростом FPS. Порядок:

1. Скачать пакет:
   **https://github.com/Aleksandr-pro/aktobe-bazar/raw/unity-1.6/integrations/unity/BazarFX-Neural.unitypackage**
2. В Unity: `Assets → Import Package → Custom Package…` → выбрать файл.
3. **Built-in RP**: повесить `BazarFXController` на камеру, в инспекторе выставить
   `mode = Neural`, `quality = High`, включить `TAA`.
4. **URP**: в `Project Settings → Player → Scripting Define Symbols` добавить `BFX_URP`,
   затем в `Universal Renderer Data` нажать `Add Renderer Feature → BazarFX Neural Upscale`.
   В URP Asset поставить **Render Scale = 0.5** — именно это и даёт экономию пикселей.
5. Проверить на своём железе: `Window → Analysis → Profiler`, смотреть GPU-время
   и счётчик FPS до/после. Ориентир: сцена в 50% + сеть ≈ на 30–50% меньше
   пиксельной нагрузки при картинке ближе к нативной, чем билинейный апскейл.

Если проекта нет, но игра собрана на Unity (IL2CPP), «вживить» пакет в готовый APK
нельзя — это не поддерживается ни нами, ни Unity.

## Итог

- Хочется прямо сейчас и без исходников → **APK 1.7 + пресет «Киберспорт»**.
- Хочется настоящего роста FPS → нужен свой Unity-проект → **Unity-пакет 1.6**.
- Обе версии используют одни и те же обученные веса, поэтому улучшение сети
  однажды попадёт в оба пути.
