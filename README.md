# Aktobe Bazar

Региональная платформа объявлений для Актюбинской области.

## О проекте
Платформа для размещения объявлений: продажа, покупка, работа, услуги и другие категории. Только для жителей Актюбинской области.

## Стек технологий
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Prisma + PostgreSQL
- NextAuth.js

## Как запустить

1. `npm install`
2. `cp .env.example .env.local`
3. `npm run dev`
