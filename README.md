# Project Voxel (рабочее название)

Открытая Rust-игра о строительстве и исследовании процедурно генерируемого, живого воксельного мира. Это самостоятельный проект: собственные название, код, визуальный стиль и игровые системы; неофициальный клон Minecraft.

## Статус

Сейчас формируем концепцию и технический план. Реализация ещё не начата.

## Документы

- [План проекта и MVP](docs/PROJECT_PLAN.md)

## Предварительная цель

Сначала сделать маленький, играбельный single-player прототип: перемещение от первого лица, разрушаемые и размещаемые блоки, чанки с процедурным рельефом, сохранение мира и один характерный «живой» системный элемент. Сетевую игру и крупный контент добавлять после проверки основы.
