# Project Voxel (рабочее название)

Самостоятельная Rust-песочница в воксельном мире, проектируемая **сначала для телефонов**. Цель — оригинальная игра с управлением касаниями, процедурным миром и системами, которые реагируют на действия игрока. Это неофициальная жанровая игра: не используем название Minecraft, его код, материалы или узнаваемый интерфейс.

## Цели платформ

- **Первая цель:** Android-смартфоны, включая устройства среднего и начального уровня.
- **Следующая цель:** iOS после проверки архитектуры и производительности на Android.
- Desktop вначале используется только для быстрых тестов и инструментов, а не как целевая версия игры.

## Сейчас

Rust-основа `crates/voxel-core` содержит блоки, чанк 16³, детерминированную генерацию с двумя биомами, пляжами, водой и пещерами, surface mesh с отсечением скрытых граней и отдельным проходом для жидкостей, DDA-поиск блока, потоковый `World` из чанков и модульные тесты. Нативный клиент `crates/mobile-game` на Rust/Macroquad держит кольцо чанков вокруг игрока (7×7), перестраивает только изменённые меши с бюджетом на кадр, поддерживает виртуальный стик, обзор свайпом, прыжок, добычу и установку блоков.

Клиент собирается только как нативный Android APK; WebView и браузерная оболочка не используются. Сборку выполняет GitHub Actions workflow `.github/workflows/android-apk.yml` (Rust `aarch64-linux-android`, Android SDK 36, NDK 27, `cargo-quad-apk`).

- Прямая ссылка на сборку: **https://github.com/Aleksandr-pro/aktobe-bazar/releases/download/mobile-alpha-18/project-voxel-android.apk**

APK подписан debug-ключом, архитектуры `arm64-v8a`, `armeabi-v7a` и `x86_64`, минимум Android 8.0 (API 26). Нативные библиотеки выровнены на 16 КБ, поэтому приложение запускается и на новых Android 15+ с 16-килобайтными страницами памяти. При установке нужно разрешить установку из неизвестных источников. На реальном телефоне сборка ещё не проверялась — это следующий шаг проверки.

См. [план мобильного проекта](docs/PROJECT_PLAN.md).

## Разработка

Нужен Rust stable и Cargo. Команды из корня:

```sh
cargo test --workspace
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
```

Нативный APK собирается workflow **Native Android APK** с Android SDK/NDK и `cargo-quad-apk`. Каждая успешная сборка в `main` публикуется как GitHub pre-release asset (постоянная прямая ссылка) и дополнительно сохраняется в Artifacts запуска.
