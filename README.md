# Project Voxel (рабочее название)

Самостоятельная Rust-песочница в воксельном мире, проектируемая **сначала для телефонов**. Цель — оригинальная игра с управлением касаниями, процедурным миром и системами, которые реагируют на действия игрока. Это неофициальная жанровая игра: не используем название Minecraft, его код, материалы или узнаваемый интерфейс.

## Цели платформ

- **Первая цель:** Android-смартфоны, включая устройства среднего и начального уровня.
- **Следующая цель:** iOS после проверки архитектуры и производительности на Android.
- Desktop вначале используется только для быстрых тестов и инструментов, а не как целевая версия игры.

## Сейчас

Начата платформенно-независимая Rust-библиотека `crates/voxel-core`: типы блоков, чанк 16³, детерминированная генерация стартового рельефа и тесты. Нативный экран/рендерер и сенсорное управление — следующие этапы.

См. [план мобильного проекта](docs/PROJECT_PLAN.md).

## Разработка

Нужен Rust stable и Cargo. Команды из корня:

```sh
cargo test --workspace
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
```
