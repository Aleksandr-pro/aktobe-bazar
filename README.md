# Project Voxel (рабочее название)

Самостоятельная Rust-песочница в воксельном мире, проектируемая **сначала для телефонов**. Цель — оригинальная игра с управлением касаниями, процедурным миром и системами, которые реагируют на действия игрока. Это неофициальная жанровая игра: не используем название Minecraft, его код, материалы или узнаваемый интерфейс.

## Цели платформ

- **Первая цель:** Android-смартфоны, включая устройства среднего и начального уровня.
- **Следующая цель:** iOS после проверки архитектуры и производительности на Android.
- Desktop вначале используется только для быстрых тестов и инструментов, а не как целевая версия игры.

## Сейчас

Rust-основа `crates/voxel-core` содержит блоки, чанк 16³, детерминированную генерацию, surface mesh с отсечением скрытых граней, DDA-поиск блока и модульные тесты. Начат нативный клиент `crates/mobile-game` на Rust/Macroquad: 3D-чанк, виртуальный стик, обзор свайпом, прыжок, добыча и установка блоков.

Клиент ориентирован на Android APK; WebView и браузерная оболочка не используются. Для сборки APK добавлен GitHub Actions workflow `.github/workflows/android-apk.yml`. Готового APK, проверенного на реальном телефоне, пока нет.

См. [план мобильного проекта](docs/PROJECT_PLAN.md).

## Разработка

Нужен Rust stable и Cargo. Команды из корня:

```sh
cargo test --workspace
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
```

Нативный APK собирается workflow **Native Android APK** с Android SDK/NDK и `cargo-quad-apk`. Успешная сборка публикуется как GitHub pre-release asset (прямая APK-ссылка) и сохраняется в Artifacts запуска для диагностики.
